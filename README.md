# Address Intelligence Pipeline (Internship Project)

> **Repository Notice**

This repository is intentionally kept private because it contains work completed during my internship at **Bajaj Finserv** that is subject to confidentiality and cannot be publicly shared.

## Project Overview

During my internship in the Data Science & AI Unit, I contributed to the development of an AI-powered Address Intelligence Pipeline for processing unstructured address data.

My contributions included work on:

* Address Tagger (Named Entity Recognition)
* Address Matcher (Semantic Similarity)
* Data preprocessing and normalization
* Validation pipelines
* Model evaluation and workflow development

## Why the code isn't public

The implementation, datasets, trained models, and related assets were developed as part of my internship and contain proprietary/confidential information. Out of respect for these obligations, I am unable to publish the source code or datasets.
